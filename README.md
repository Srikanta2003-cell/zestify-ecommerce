# Zestify - Online Shopping

A responsive e-commerce website built using HTML5, CSS3, JavaScript and Bootstrap.

## Live Demo

[View Live Demo](zestify-ecommerce.vercel.app)

## Features

- Responsive e-commerce UI
- Product categories
- Product listings
- Shopping cart
- Dynamic cart count
- Responsive design
- Interactive product sections

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
